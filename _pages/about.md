# Data Science Projects

- Lactate Threshold Modelling
    - Created a state of the art medical regression model for the project partner company [Davos Sport & Health](https://www.davossportshealth.ch/de/forschunglehre/kompetenz-forschung/projekte)
    - Prediction of the first lactate threshold
    - UI demonstrator for generating predictions for analysis
- Helicopter Maneuver Classification
    - Classification model for a school project with the partner company [Loft Dynamics](https://www.loftdynamics.com/) 
    using traditional ML methods for generating labeled data out of high-dimensional sensor measurements
- Virtual Quality Control for Injection Molding
    - Created a regression model using traditional ML methods
    for the school project partner institute [IWK](https://www.ost.ch/de/forschung-und-dienstleistungen/technik/maschinentechnik/iwk-institut-fuer-werkstofftechnik-und-kunststoffverarbeitung)
    - Adjusted $$ R^2 $$ of $$ 0.943 $$
    - Feature optimization with the goal of minimizing the required sensors within the process
- Various Exercise Projects:
    - MNist with $$ >92\% $$ classification accuracy
    - CIFAR-10 with $$ >90\% $$ classification accuracy
    - Animal Species Classification with $$ >80\% $$ classification accuracy
